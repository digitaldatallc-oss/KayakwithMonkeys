# Monkey Business Kayaks LLC

Production-preview static website for **KayakWithMonkeys.com**.

## Included
- Responsive premium homepage
- Single and tandem pricing
- Wildlife and Silver River sections
- Reservation request page
- Privacy, terms, and media credits
- SEO metadata, sitemap, robots.txt, schema markup
- GitHub Pages deployment workflow
- Custom-domain CNAME

## Publish with GitHub Pages
1. Upload all files to the repository root and commit to `main`.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions**.
4. The included workflow deploys the site.

## Required before accepting paid reservations
- Replace the reservation email workflow with the final FareHarbor booking URL/embed.
- Confirm final pricing, policies, age/weight rules, park fees, phone number, and operating hours.
- Configure the domain DNS for GitHub Pages or the selected host.
- Have the waiver, cancellation terms, privacy policy, and operating language reviewed for the business.

## Booking integration
When a FareHarbor booking URL is available, replace links to `book.html` with that URL, or embed the FareHarbor lightframe code on `book.html`.
